# Changelog

## 0.17.1
- Оверлей выделения поднят на самый верхний слой окон (screen-saver), поверх полноэкранных приложений и окон ошибок
- Сервер: gzip/brotli, ETag/304, лимит параллельных скачиваний, rate-limit по IP, SQLite WAL, ротация логов, graceful shutdown, опциональный HTTPS напрямую
- Сервер: защита /register токеном (AUTH_TOKEN), клиент передаёт Bearer-токен
- Клиент: ретраи к API-провайдерам на временные сбои (429/5xx), лог ошибок клиента в userData/ludr-error.log
- Клиент: убран небезопасный обработчик скачивания обновления (теперь только через манифест с проверкой sha256)
- Electron обновлён до 43.x, зависимости без известных уязвимостей
- Деплой: примеры systemd-юнита и nginx-конфига в luder-server/deploy/

## 0.17.0
